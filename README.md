# تصنيف البرمجيات الخبيثة (PayloadClassifier) 🛡️

أداة تحليل ساكن (Static Analysis) خفيفة الوزن وعالية الأداء لفحص وإحكام تحليل الملفات التنفيذية من نوع (Portable Executable - PE). تم تطوير هذه الأداة للوفاء بالمتطلبات الأكاديمية وإثبات استخراج الخصائص، وحساب العشوائية (Shannon Entropy)، وشجرة القرار (Decision Tree Engine) **باستخدام مكتبات بايثون القياسية فقط بدون أي مكتبات خارجية (Pure Python)**.

---

## 🔑 الميزات الرئيسية
- **اعتماد كامل على Pure Python**: استخدام المكتبات المدمجة فقط (`struct`, `math`, `json`, `sys`, `os`) للالتزام بمتطلبات التنفيذ دون الحاجة لتثبيت أي حزم خارجية.
- **محلل الهيكل الداخلي (Custom PE Parser)**: تحليل ترويسات DOS و NT والترويسات الاختيارية وقوائم الأقسام لاستخراج البيانات الوصفية الدقيقة للملف.
- **محرك حساب العشوائية (Entropy Engine)**: حساب درجة العشوائية لكل قسم وللملف ككل لكشف أدوات التشفير والضغط والتمويه (Packing/Obfuscation).
- **التصنيف بالذكاء الاصطناعي**: تقييم الخصائص المستخرجة عبر نموذج شجرة القرار المخزن بملف (`model.json`).
- **القضاء على الإنذارات الخاطئة**: ضبط حد العشوائية (7.75) لضمان عدم تصنيف أدوات النظام السليمة (مثل `cmd.exe` و `calc.exe`) كبرمجيات خبيثة.
